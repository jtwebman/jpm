# npm-package-arg conformance cases

The `*.json` files here are derived from the test suite of
[npm-package-arg](https://github.com/npm/npm-package-arg), npm's parser for dependency specs,
at commit `31dc824945365794c9569037805a0727026647d4`. They are generated by
`tests/conformance/gen/npm-package-arg.mjs`, which runs each of npm-package-arg's `test/*.js`
files against a stub of tap and of npa and records every spec a test hands npa with what the
test expects back. npm-package-arg is licensed under the ISC License, Copyright (c) npm, Inc.; its license
text is in `LICENSE` beside this file.

Each row is one spec: `arg` (a CLI argument, as `npa(arg, where)`) or `name` and `spec` (a
package.json entry, as `npa.resolve`), the `where` it was read from, the platform whose reading
the file pins (`any`, `posix` or `win32`), and either `expect` (the fields the test asserts) or
`throws`.

`tests/conformance/npm_package_arg.rs`, built into jpm's unit tests from `src/spec.rs`, reads every
row as jpm reads that spec and compares what jpm keeps of npa's result. The differences jpm
makes on purpose are listed there, each with its reason.

To regenerate:

```sh
git clone https://github.com/npm/npm-package-arg /tmp/npa
git -C /tmp/npa checkout 31dc824945365794c9569037805a0727026647d4
node tests/conformance/gen/npm-package-arg.mjs /tmp/npa
```
