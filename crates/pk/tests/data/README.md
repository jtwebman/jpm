# Test data

The `*_test.json.gz` files are test vectors from Project Wycheproof
(https://github.com/C2SP/wycheproof, `testvectors_v1`), Copyright 2016 Google Inc., licensed
under the Apache License, Version 2.0 (see `WYCHEPROOF-LICENSE`). They are stored gzipped; the
JSON inside is unchanged.

The rest is jpm's own: `rsa2048.der`, `rsa3072.der` and `rsa4096.der` are keys generated for
these tests, and `rsa_odd_keys.json.gz` is written by `rsa_odd_keys.py`.
